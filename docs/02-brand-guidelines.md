# Brand Guidelines

## Character

Spatial precision: minimal, editorial, modern, premium, engineering-led, professional, and elegant. The intended references are product-quality mapping and documentation experiences, rather than generic framework templates.

## Identity

Use the existing personal monogram/logo; do not redesign it unless requested. Use restrained decorative GIS motifs (grid, contours, coordinates, projection labels, scale or north arrow) below 5% opacity.

## Typography and colour

| Role | Choice |
| --- | --- |
| Heading | Manrope |
| Body | Inter |
| Metadata/code | JetBrains Mono |
| Text | `#111827` |
| Accent | `#0F766E` |
| Accent hover | `#115E59` |
| Background/surface | `#FAFAFA` / `#FFFFFF` |
| Border/muted text | `#E5E7EB` / `#6B7280` |

Use 16px as the standard large radius and soft, minimal shadows. Details and reusable tokens are in [05-design-system.md](05-design-system.md).

## Voice

Write clear, factual Bahasa Indonesia for user-facing research content, with concise English where established by the page. Avoid inflated claims, vague superlatives, and unverified metrics. Use “not documented” when a source does not provide the fact.
